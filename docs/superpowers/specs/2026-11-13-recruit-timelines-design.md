# Natural recruiting timelines

The approved feature replaces a public countdown with a readable, uncertain recruiting process. Most prospects keep their timing private; relationships reveal qualitative clues. A minority announce a week and may explain a delay. Visits, school fit, competition and stable personality influence readiness. Signing windows and flip defense remain intact.

## Approach
Hiding the old date alone would preserve a mechanical countdown and targeting exploit. Pure weekly randomness would remove useful agency. Use deterministic, season-scoped readiness for every prospect instead. The implementation chooses numeric tuning, while preserving the approved behavior and existing action economy.

Keep current offers, list cuts, decisions and commitments when loading an existing save. Discard legacy private deadlines, not recorded history. No new storage schema, dependencies, payment, publication, or changes to signing/flip eligibility. Render helpers expose only public information and never draw gameplay randomness. Same saved state and choices replay identically.
