# Meshy prototype sprites

Prototype only; not referenced by the game build. Trophy and helmet were generated
with Meshy text-to-3D (preview, then PBR refine) and rendered to transparent PNGs
with three.js. Sprites sit in `assets/meshy-prototype/`; the title-screen mockup
is `docs/mockups/title-screen-meshy.html`. The source GLBs are not committed (8-10 MB each).
