   it as a browser zip, `shasum -a 256` that file and compare with the digest above. Note

3. Unzip, then verify the app: `codesign --verify --deep --strict "Dynasty Lab.app"`
   (ad-hoc signature, so `spctl` will still object; that is expected until notarisation).
4. Confirm the version: `defaults read "Dynasty Lab.app/Contents/Info" CFBundleShortVersionString`
   should read `0.12.24`.
5. Back up the current app first: copy `/Applications/Dynasty Lab.app` to
   `~/Applications/Dynasty Lab 0.12.23.app` (keep the earlier 0.12.x backups too).
6. Replace `/Applications/Dynasty Lab.app` with the new bundle. Do not touch save files: they
   live in app data, not the bundle (17 save files existed at v0.12.23; confirm the count is unchanged).
7. Launch and check by eye: the title screen shows the gold trophy beside the menu; start or
   continue a dynasty, open Game Lab, and both teams show helmets with their logos (the home
   helmet mirrored). If a champion season is in the save, its Season Review shows the trophy.

If anything is wrong, restore the 0.12.23 backup; saves are unaffected either way.

## Traps

- `index.html` is generated; run `npm run build`. Version drift and docs drift are tested
  (`tests/version.js`, `tests/docs-consistency.js`).
- A fresh container has no dev dependencies: run `npm ci --ignore-scripts` before `npm test`
  or `fake-indexeddb` fails 11 suites with "Cannot find module".
- Desktop artifacts are only built when the head commit message has `[release-ci]` (or `[desktop-ci]`).
- Meshy asset generation is credit-metered; the helmet and trophy sources (GLBs) are not committed.
  Regenerating the atlas only needs a transparent side-view render of one helmet:
  `python3 tools/build-helmet-atlas.py <side.png>`.
