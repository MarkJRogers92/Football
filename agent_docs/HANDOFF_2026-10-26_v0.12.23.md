- **League parity is high.** Ten seasons: 9–10 distinct champions; prestige spread narrows 16.8 → 14.3.

## Traps this work already hit — don't rediscover them

- **The offseason is interactive.** One `runOffseason()` advances one phase and can
  stop on a career choice or an unrun camp. Any loop must drive phases and assert the
  year advanced; several tools silently froze before this was fixed.
- **Tools lied twice.** `save-size.js` hardcoded `seed: 7` (so a "two-seed" soak was
  one seed), and its loop froze at season 11. Both fixed — always check the tool
  before trusting a number.
- **Filling to 85 is not roster repair.** Programs sit at 85 with a skewed shape, so
  a fill-only fix changed nothing (36 → 42 thin K/P). The repair pass, prioritising
  critical positions, is what worked.
- **Most of the app is one file.** Parallel edits to `app.js` collide; put new
  presentation in its own module registered in `tools/build.js`, and give delegated
  work its own git worktree.
- **`index.html` is generated.** Never hand-edit; run `npm run build`.
- **Version drift is tested.** `tests/docs-consistency.js` requires VERSION.txt,
  CHANGELOG, README, the handoff and STATUS.md to agree, with STATUS naming an
  ancestor commit.
