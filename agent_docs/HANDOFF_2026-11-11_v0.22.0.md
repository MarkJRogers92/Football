- `npm run audit`: exits 0.

Three failed: `game-engine-v2-lifecycle-browser`, `fun-features-browser` and `live-game-lock-browser`. - Not run: desktop packaging (`npm run desktop:make*`) and the packaged smoke test. `desktop/` was not touched, but `tools/build.js` now adds a CSP and a service-worker registration. `pwa.js` skips the desktop shell and `file:` URLs. Nobody has opened the packaged app to check.

## Owner decisions (2026-11-11)

- **Signing certificates: no.** Mac and Windows builds keep the one-time install warning.
- **Licence and price: no, for now.** There is no `LICENSE`. About has credits for the font and art.
- **Program nicknames: yes.** Done in `mascots.js`. Program *names* were not changed: the name is the key in saves, schedules and about a thousand test references.
- **Alpha saves migrating to 1.0: not necessary.** Everything so far still loads old saves anyway.
- **Play calling depth and crash reports: left to the agent.** Calls stop at one per drive plus key third-down defense. Crash reports stay on the device; nothing is sent anywhere.

## What is left, in the order I would do it

1. **Rerun the whole browser set once** (`npm run validate:full`, or `/tmp/.../runall.sh`-style suite by suite) to confirm a clean pass from start to finish, then check the packaged desktop app opens and plays: `npm run test:desktop-smoke`.
2. **Timeouts in the live game** (left out of v0.19). Add a `timeout` decision in the last two minutes of each half in `game-engine-v2-gameday.js`, following `createTempoDecision`. Keep it behind `session.driveCall` like the other v0.19 calls so Coach big moments and old saves are unchanged.
3. **Signing day and the portal one name at a time** (left out of v0.20). The offseason stops in `offseason-stops.js` currently send the coach to the screen that holds the decision. The next step is to resolve the coach's own targets as a short sequence of events.
4. **Fast test tier.** Split `npm test` into a parallel fast set (under two minutes) and a slow simulation set. CI's 60-minute limit has room, but local iteration is slow.
5. **Test hooks in the release build.** `window.__DL_TEST__` still ships. Gate it behind a build flag and give the browser tests a test build.
6. **Real devices and real players.** iPhone Safari, Firefox, a screen-reader pass, and watching three new players to week 4. None of this can be done from a container.
7. **Longer term:** split `app.js` (565 KB) by domain and generate the build's module list from a manifest; add a linter once that structure allows it.

## Things that cost time, so you do not repeat them

- **The Next button on This Week is handled by `next-action.js`**, which calls `stopImmediatePropagation`. A handler set on `#hubAdvance` in `app.js` never runs once guidance is installed. Hook new behaviour into `next-action.js` (see the `DynastyOffseasonStop` call).
- **Engine extensions are block scoped.** A function declared in one of the files listed in `engineExtensionFiles` (`tools/build.js`) is not visible from `app.js` or from presentation modules. Expose it with a `globalThis.Dynasty…` name. `recruitingActions` is one such private name.
- **The Node test shim is not a DOM.** Elements lack `insertAdjacentElement` and `classList.toggle`. Guard calls to DOM methods in code that runs during unit tests.
- **Engine golden hashes.** `tests/play-model.js` and `tests/game-cast-field.js` pin a digest of simulated games. Any change to play outcomes (as in v0.17.2) moves them. Re-take them and say why in a comment. `docs/v0100-CALIBRATION.json` must be regenerated and stamped (`npm run calibrate:game-engine-v2`) after any change to `game-engine-v2.js`, `game-engine-v2-adapter.js` or the compare tool.
- **`sw.js` and `index.html` are generated.** Run `npm run build` after a version bump or a change under `assets/` and commit both; CI checks them.
- **`phone-a11y.css` uses `!important` on explicit selectors.** Before adding one, check it does not shrink text that is already larger: build once without the file and compare computed sizes.
- **Version bumps touch six files** (`VERSION.txt`, `APP_VERSION` in `app.js`, `package.json`, `package-lock.json`, `README.md`, `CHANGELOG.md`) plus `docs/roadmap/STATUS.md`'s "Last reconciled" line and `agent_docs/latest_session_work.md`. `tests/docs-consistency.js` fails if any disagree.
- **New dynasties start with staff recruiting on.** `tests/helpers/start-new-dynasty.js` turns it off unless a test passes `{staffRecruiting:true}`, so older suites keep a hand-run board.
- **Tests that assume a bare kickoff.** A fully coached game can now open on a drive call. Tests that start a live game and click Next must delegate a pending decision first.
